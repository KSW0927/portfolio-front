Csslistv4.0 or higher

에디터에서 문서를 작성할 때 적용할 CSS 파일 링크를 설정합니다.

경로는 전체 경로나 절대 경로를 사용합니다.

 

여러 개의 CSS 파일을 추가할 수 있으며 설정값은 콤마(,)를 구분자로 입력하면 됩니다.

 

Parameters

설정한 CSS파일 반영

Sample Codes

var CrossEditor = new NamoSE("test");
CrossEditor.params.Csslist = "/ce/css/common.css,/ce/css/ce4.css";
CrossEditor.EditorStart();
