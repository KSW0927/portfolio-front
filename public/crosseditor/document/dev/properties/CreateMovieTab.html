Method

Event

 

 

CreateMovieTabv4.6.0.16 or higher

동영상 플러그인 화면에 표시할 탭의 종류를 설정합니다.

 

설정값은 파이프(|)를 구분자로 하여 입력하시면 됩니다.

예를 들어, 파일 탭과 소스입력 탭을 화면에 표시하는 경우 "1|3"과 같은 형식으로 설정합니다.

 

단, 아무 값도 입력을 하지 않았을 경우 모든 탭이 화면에 표시됩니다.

 

Parameters

1

파일 탭

2

주소(URL) 탭

3

소스입력 탭

 

Sample Codes

var CrossEditor = new NamoSE("test");
CrossEditor.params.CreateMovieTab = "0|1";
CrossEditor.EditorStart();
