UseTagCleanerOptionsv4.5.2.01 or higher

태그 정리 옵션에 따라 태그 정리 기능을 실행합니다.

설정 시 GetValue, GetBodyValue, SetValue, SetBodyValue, 툴바/메뉴바에서 태그 정리 기능 실행 시 동작합니다.

 

Parameters

nesting

중첩 태그 정리

empty

빈 태그 정리

 

Sample Codes

var CrossEditor = new NamoSE("test");
CrossEditor.params.UseTagCleanerOptions = "nesting | empty";
CrossEditor.EditorStart();
