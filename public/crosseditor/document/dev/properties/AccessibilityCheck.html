AccessibilityCheckv4.6.0.22 or higher

GetBodyValue/GetValue 함수 호출 시 ‘웹 접근성 검증' 후 값이 리턴 되도록 설정합니다.

 

웹 접근성 검증이 완료되지 않은 경우 'CrossEditor MSG: 웹 접근성 위반' 텍스트가 리턴 됩니다.

웹 접근성 검증이 완료된 경우 현재 편집 중인 문서의 내용을 HTML형식으로 리턴 합니다.

 

Parameters

TRUE

웹 접근성 검증 체크

FALSE

웹 접근성 검증 체크하지 않음 (기본 값)

 

Sample Codes

var CrossEditor = new NamoSE("test");
CrossEditor.params.AccessibilityCheck = true;
CrossEditor.EditorStart();
